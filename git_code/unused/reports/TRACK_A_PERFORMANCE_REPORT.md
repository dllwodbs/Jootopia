**정의**: 랭킹 점수와 실제 수익률의 상관관계

**결과**:
- 단기: 0.0120 (낮은 양의 상관관계)
- 장기: 0.0160 (가장 높음)
- 통합: 0.0105 (단기보다 낮음)

**해석**:
- 모든 랭킹이 양의 IC를 보임 → 랭킹이 높을수록 수익률이 높은 경향
- IC 값이 낮은 이유: 시장 효율성, 노이즈, 기타 요인들

- 단기: 0.0374
- 장기: 0.0443 (가장 높음)
- 통합: 0.0407 (단기보다 높음)

**해석**:
- Rank IC가 IC보다 높음 → 순위 기반 예측력이 점수 기반보다 우수
- 통합 랭킹의 Rank IC가 단기보다 높음 → 장기 랭킹 가중치(0.8)의 효과
